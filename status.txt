TODO
----
- Collision detection and retry
    Multiple transmitters sending simultaneously will corrupt each other's packets.
    Planned approach: random backoff before each transmit (CSMA-style).
    On no-ACK, retransmit after a random delay, with exponential backoff up to a
    max retry count. Requires ACK support on the receiver side (receiver sends a
    short ACK packet keyed on lab_id + sensor_id + a sequence number).
    Sequence numbers are not currently in the packet header and will need to be
    added (suggests a protocol v2 header change, or an optional header extension).

- Replace mock sensors with real hardware reads
    sensors.py read_temperature() and read_door() have placeholder bodies.
    Swap with ADC reads / GPIO reads when hardware is available.

- Host-side parser
    Receiver currently prints human-readable lines over USB serial.
    A host Python script should parse this output (or switch receiver output
    to JSON for easier machine parsing).

- Multi-lab support
    lab_id is configurable but untested with values other than 1.

- Over-the-air configuration or firmware update strategy (longer term)
